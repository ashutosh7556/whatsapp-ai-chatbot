 
# 🤖 WhatsApp AI Chatbot

A WhatsApp chatbot built with Node.js, Express, and the WhatsApp Cloud API.

## ✨ Features

- 💬 Automated replies
- 📋 Interactive menu
- 🤖 AI-ready architecture
- 🔗 Webhook integration
- ⚡ Fast & lightweight

## 🛠️ Tech Stack

- Node.js
- Express.js
- WhatsApp Cloud API
- Axios
- dotenv
